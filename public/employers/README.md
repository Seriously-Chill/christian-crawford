# Employer logos

White logo assets gathered for portfolio use. Color assets were recolored to white while retaining transparency. HealthWarehouse's SVG was already the site's white footer mark.

| Asset | Source |
| --- | --- |
| `healthwarehouse-white.svg` | Official HealthWarehouse website footer: https://www.healthwarehouse.com/assets/images/logo-footer.svg |
| `ingage-white.svg` | Official Ingage Partners website logo asset: https://cdn.prod.website-files.com/668c1662c546ac4eea71dcb4/668c4ba15a33c8acb6c09147_Ingage%20Logo.svg |
| `kroger-white.svg` | Official Kroger website logo asset: https://www.thekrogerco.com/wp-content/uploads/2026/06/logo.svg |
| `cbts-white.png` | Official CBTS website logo asset: https://www.cbts.com/hs-fs/hubfs/CBTS%20COM/CBTS_logo_dark_teal.png |
| `cincinnati-bell-white.svg` | Cincinnati Bell wordmark from Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Cincinnati_Bell_wordmark.svg |
| `trivantis-white.png` | Trivantis logo from Seeklogo: https://seeklogo.com/vector-logo/606101/trivantis |
| `ginghamsburg-white.png` | Official Ginghamsburg website logo asset: https://ginghamsburg.org/wp-content/uploads/2020/09/ginghamsburg-logo-small.png |

The Trivantis logo is from a third-party logo archive because an official current asset was not readily available. Cincinnati Bell and CBTS are both included because the profile identifies the employer as CBTS, Cincinnati Bell.

The Ingage and Cincinnati Bell SVGs have tightened `viewBox`/`width`/`height` values so their transparent margins don't offset them when laid out beside the other logos. The artwork paths are unchanged.
