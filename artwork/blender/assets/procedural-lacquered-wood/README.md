The shader is procedural and includes a custom lacquered-wood node group. It contains a Musgrave texture node; Blender 4.1+ automatically converts legacy Musgrave shader setups to Noise Texture nodes. The source asset is preserved untouched. Compatibility with the nested study's Eevee Next render engine still needs a visual check before assigning it to the final render.
