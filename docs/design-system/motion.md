# Motion

Real, sourced interactions — read from the site's own `style.css`, `custom-frontend.min.css`, `page-transitions.min.js`, and inline `<script>`/`<style>` blocks across all 6 captured pages (Home, Product, Innovations, Contacts, About us, News), not guessed. An earlier pass of this file got two of these wrong (see corrections below) — this version was checked against the actual CSS/JS on every page, not just Home.

**Smooth scroll.** Lenis runs site-wide — `<html class="lenis">` on every page, `lenis.min.js` its own script. The init call is explicit, inline on every page:
```js
new Lenis({ duration: 1.2, easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
  direction: 'vertical', gestureDirection: 'vertical', smooth: true, smoothTouch: false, touchMultiplier: 2 });
```
`duration`/`easing` happen to match Lenis's own library defaults, but `touchMultiplier: 2` does not (library default is `1`) — carry that one real override, not "pure defaults."

**Ripple hover** — real, confirmed in `style.css` (identical md5 across all 6 pages, so sitewide, not homepage-only): applied via a literal `.ripple` class to the six product-category cards on Home and the Product index only, explicitly disabled inside `.other-products` cross-link sections. A `::after` pseudo-element, centered, holds a radial texture (`ripple.png`, `mix-blend-mode: multiply`; the PNG itself wasn't captured, texture is approximated). `.ripple:hover:after{animation:ripple .8s ease-out forwards}`, keyframes `0%{opacity:.6;scale:1}` → `100%{opacity:0;scale:3}`, gated behind `@media (hover:hover) and (pointer:fine)`. Because the rule re-declares the identical `animation` value on every `:hover`, some browsers won't restart it on repeat hovers — it can read as "fires once" even though the source code doesn't special-case that.

**Card surface is a glass tint, not a filled gray box** — correction: the actual card (`Продукція` page, element `4827d4a`) is `background-color:#FFFFFF1A; border:1px solid #FFFFFF1A; border-radius:24px; padding:24px` (`16px` on mobile) — a barely-there 10%-opacity white fill+border, not `surface-raised`/`#F8F8FA`. This treatment only reads on a colored or dark ground (same rule as `ContactForm`'s translucent inputs) — on our light `surface` pages it has to be adapted (ink-tinted, not white-tinted) rather than copied literally, or it's invisible.

**Page-transition preloader** — correction: this was previously documented as a blue-gradient overlay; the real `<e-page-transition>` element (`page-transitions.min.js`, real Elementor Pro web component) is a plain **white** (`background:#fff`) full-viewport overlay, `z-index:10000`, holding a **static** (non-spinning) `70px`-wide logo mark that only fades — no gradient anywhere in this component. Real timing: `--e-page-transition-animation-duration:700ms` for the overlay itself, `--preloader-fade-duration:.5s` for the icon's own fade nested inside that. Entrance animation = fade-out (reveals the page), exit = fade-in (covers before navigating).

**Sitewide staged entrance system** — real, sourced, previously undocumented: Elementor's `animated`/`animated-slow` + `fadeIn`/`fadeInUp` classes, confirmed on Home (13 elements), Innovations (7), News (3). `.animated-slow{animation-duration:2s}` (used on hero-tier content), `.animated{animation-duration:1.25s}` (used elsewhere). `fadeIn`: opacity 0→1. `fadeInUp`: opacity 0→1 **and** `translate3d(0,100%,0)→none` — slides the element's own full height, not a small nudge. Elements are staggered via an explicit per-element delay in 100ms increments (e.g. Home hero: headline 100ms → tagline 200ms → primary CTA 300ms → secondary CTA 400ms → image 500ms). This plays once, on scroll into view (or on load for above-the-fold content) — it's the site's main "premium" cue and the thing our own reveal timing under-matched most.

**Accordion (vertical expand)** — real, sourced from the About-us page's "production process"/"values" list (`.vertical-acc`): collapsed state is `height:0; overflow:hidden; margin:0`; opening transitions `height` and `margin` together, `1s cubic-bezier(0.4, 0, 0.2, 1)` (Material "standard" easing, not `ease-out`). Distinct from the ripple/entrance timings above — this is the slowest, most deliberate motion on the site, reserved for progressive-disclosure content, not decoration.

Apply real interactions to the elements the source actually uses them on — don't spread the ripple to every card or button just because it exists once, and don't reach for the accordion's 1s easing anywhere faster-paced.
