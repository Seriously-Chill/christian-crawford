# Button

The kit defines exactly one button shape: `radius-pill` (a literal 100px, not a generic "fully round" value), padding `12px 24px`, label in `label` (Poppins 16px/500, letter-spacing −0.03em, text-transform none). Default state is `surface` (white) fill with a `primary`-colored label. Hover/focus swaps to a solid `primary` fill with a `surface` (white) label — there is no separate "secondary" filled variant in the real CSS; a bordered/ghost button (as used next to a primary CTA in the hero) is the same shape with a transparent fill and a `primary` border/label instead. Never give a button a different radius or padding — the site has no square or `radius-lg` button anywhere.
