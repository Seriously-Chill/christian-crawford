# RetailerLogos

The "You can buy Christian Crawford here" strip repeated on every product-category page: a plain wrapping row of real retailer logos (`assets/Retailers/`) on `surface`, no card, no border — the logos carry their own whitespace. Don't resize or recolor them; lay out at whatever width they render, wrapped to as many rows as needed.

Note: this component and its retailer logos are part of the original igel.ua site this design system was reverse-engineered from. They were explicitly not carried into the Christian Crawford portfolio build (no supermarket-partner section applies to a personal site) — kept here only for completeness of the design system export.
