# ProductGrid

The "All types" section on every category page: a grid of that line's individual products, name only (no price, no image reached this build — see the root README's Iconography note). Counts vary for real reasons — Washing gels 7, Floor cleaning 5, Conditioners & rinses 4, Toilet bowl cleaners 4, Cleaning products 7, Dishwashing gels 8 — don't pad or trim a real line-up to match another category. Each tile is `surface-raised`/`radius-sm`, name set in `label`.
